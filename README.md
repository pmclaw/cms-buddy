# 小招 Buddy 客户端

按 Figma 设计稿（`Untitled` / fileKey `sA7xJxjQJE7uXsdcLApq0l`）复刻的「小招 Buddy」桌面端 Web 应用，页面均为可交互实现。

技术栈：React 19 · TypeScript · Vite 8 · Tailwind CSS v4 · radix-ui 基础组件 · React Router 8。

## 快速开始

```bash
npm install
npm run dev      # 本地开发
npm run build    # 产出 dist/（静态 HTML/CSS/JS）
npm run preview  # 预览构建产物
npm run lint     # oxlint
```

## 页面结构

| 路由 | 页面 | 对应设计稿 |
| --- | --- | --- |
| `/` | 首页（新任务）：吉祥物、标语、推荐问法、输入框 | 首页画板 |
| `/buddy`、`/buddy/:id` | 回答详情页：用户提问、任务处理过程时间轴、回答正文、免责声明、操作条 | 对话画板 ×2 |
| `/skills` | 技能中心：分类筛选 + 官方精选 Tab + 搜索 + 卡片网格 + 空状态 | 技能中心画板 |
| `/skills/:id` | 技能详情：概览/文件/版本、框架表格、文件预览、元信息 | 技能详情画板 |
| `/experts` | 专家助理：分类、排序、专家卡片、详情弹窗（典型提问示例） | 专家助理画板 |
| `/automation` | 自动化任务：任务列表、筛选、从模板创建、创建/编辑/删除 | 自动化任务画板 ×3 |

## 可交互行为

- 侧边栏：新任务 / 技能中心 / 专家助理 / 自动化任务 四项导航；历史对话与自动化任务列表在各页面样式一致，点击都进入回答详情页。
- 输入框（`Composer`）：附件 chip、技能多选、专家单选、模型切换、Enter 发送；提交后进入回答详情页，逐条播放「任务处理过程」再输出回答（自动滚动）。
- 回答详情页：思考过程可折叠、点赞/复制等操作反馈、可继续追问；`/buddy/:id` 用于历史会话与自动化任务结果，`/buddy?q=` 用于新提交的问题。
- 技能中心：关键词搜索、全部/官方精选切换、分类筛选、卡片进详情、空状态插画。
- 专家助理：搜索、分类筛选、按使用次数/人数/点赞排序、详情弹窗、「立即咨询」带入回答详情页。
- 自动化任务：状态筛选、名称搜索、卡片更多菜单（执行一次/暂停/编辑/删除）、删除二次确认、创建与编辑表单（周几多选、时间、接收渠道、回复模式）、模板创建。

## 设计还原说明

- 颜色/字号/圆角取自设计稿变量与图层信息：正文标题 `#283253`、辅助文字 `#657386`、品牌蓝 `#185ec8`、分隔线 `#d7d7e1`、页面底色 `#f2f2f7`、输入框描边 `#644380`，卡片描边 `rgba(0,0,0,0.05)`、圆角 8px。
- 图标与插画使用 Figma 导出的原始资源，落地在 `src/assets/figma/`（Logo、导航图标、分类图标、卡片统计图标、角色头像、首页吉祥物、空状态插画、反馈/聚力/企业微信图标）。
- 角色头像按设计稿「纯色圆形底 + 人物图按固定窗口裁切」的方式合成，换算参数见 `src/data/assets.ts`。
- 页面文案、专家/任务数据来自设计稿内的真实文案；技能中心的分类导航与业务归属方为业务侧指定/占位数据，同样集中在 `src/data/` 下（`skills.ts` / `experts.ts`）。
